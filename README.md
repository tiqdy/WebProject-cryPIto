🪙 cryPIto 
cryPIto is a cryptocurrency-themed web project designed to provide users with an engaging and informative interface to explore digital currencies, market data, and crypto-related news. 
The project focuses on a modern UI, responsive design, and clean separation between structure (HTML) and styling (CSS).

🌐 Project Overview
The goal of cryPIto is to introduce users to the world of cryptocurrency through a easy-to-navigate website. It showcases featured cryptocurrencies, highlights key benefits of 
using crypto, and presents news and market insights in an organized layout.

✨ Features
📊 Featured Cryptocurrency Section
📰 Crypto News Widget with slideshow effect
💎 Key Benefits of Using Cryptocurrency
📱 Responsive Design (desktop & mobile-friendly)
🧾 Register page 

📌 Notes
This project was created for educational and demonstration purposes. It does not provide real-time financial data and should not be used for actual trading decisions.
